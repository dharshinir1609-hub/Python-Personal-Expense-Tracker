# Personal Expense Tracker

## Project Description
Personal Expense Tracker is a simple menu-driven Python application used to record and manage daily expenses.

## Features
- Add new expenses
- View all recorded expenses
- Calculate total spending
- Handle invalid amount inputs

## Technologies Used
- Python 3.14
- Lists and Dictionaries
- Functions
- Loops and Conditional Statements
- Exception Handling

## How to Run

1. Install Python.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
py expense_tracker.py
```
